How to read this

  • Each setting runs twice: once with the fixed model and once with the original (the upstream commit this repository started from). Both get exactly the parameters the website would send.
  • AC is the automated coder, SAR and SIAR the superhuman and superintelligent AI researcher, and ASI artificial superintelligence, as defined by the AI Futures Model. AIR-25× is when AI speeds up software progress 25-fold.
  • The examples reproduce the cases in BUGS.md. "Taste 10 SD" is not a bug: both models give nonsense there, because calibration assumes human-level research taste in the past.
  • Everything runs in your browser with Pyodide; the first load downloads about 30 MB. Settings are kept in the URL, so a link reproduces them.
